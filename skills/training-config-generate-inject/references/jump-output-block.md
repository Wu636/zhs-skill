# 跳转/结束输出标准段（可直接复用）

线性基础版/口语剧本的每个阶段提示词末尾都要有这一段，作为最高优先级的输出约束。
`normalize` 自动补的文本与本文件一致；手写或优化提示词时按状态复制对应版本，
只替换其中的跳转词和字符数。

放置位置：阶段 `**提示词**` 的 ```` ```markdown ```` 围栏内、最后一个约束段之后；
同一阶段只保留一份，已有 `# 跳转输出` / `# 结束输出` 时不要重复添加。

## 非末阶段：跳转输出

```markdown
# 跳转输出（最高优先级，覆盖以上所有要求）

- 跳转词是平台识别的控制信号：平台按整条消息精确匹配，多一个字、一个标点、一个换行都不会跳转。

- 未满足全部过关条件时，严禁输出跳转词。

- 一旦判定过关，不要再说“这一项已经说清”之类的确认语，不要补充说明，也不要再提新问题，本条消息只能是“接下来我们将进入下一阶段”这 12 个汉字，前后不得有空格、标点、换行或其他任何字符。

- 学生刚回答完最后一处待核事项时，立即判断是否过关；过关就直接只发跳转词，不要再追加确认问题。

- 严禁把确认语、过渡语与跳转词放在同一条消息里。以下写法平台都识别不到，全部禁止：

  - 这一项已经说清。接下来我们将进入下一阶段

  - 好的，接下来我们将进入下一阶段。

- 发送前自检：本条消息去掉首尾空白后必须恰好 12 个字符，且逐字等于“接下来我们将进入下一阶段”；多出任何字符就删到只剩跳转词再发送。
```

## 末阶段：结束输出

```markdown
# 结束输出（最高优先级，覆盖以上所有要求）

- 结束语是平台识别的控制信号：平台按整条消息精确匹配，多一个字、一个标点、一个换行都不会结束。

- 阶段过关条件未全部满足时，严禁输出结束语。

- 需要结束时，本条消息只能是“本次实训到此结束”这 8 个汉字，前后不得有空格、标点、换行或其他任何字符。

- 最后的点评、致谢、总结必须放在上一条消息里说完；严禁与结束语放在同一条消息里。以下写法平台都识别不到，全部禁止：

  - 本次实训到此结束。

  - 以上是本次实训的全部内容，本次实训到此结束

- 发送前自检：本条消息去掉首尾空白后必须恰好 8 个字符，且逐字等于“本次实训到此结束”；多出任何字符就删到只剩结束语再发送。
```

## 替换规则

- 阶段有自定义 `flowCondition` 时，把两处跳转词都替换成该词，并把“12 个汉字/字符”改成实际字符数。
- 跳转词不是纯汉字（如 `TASK_COMPLETE`）时，“这 N 个汉字”改为“这 N 个字符”。
- 末阶段使用教师指定的其他结束语时，同样替换并重算字符数；不要在未确认结束语时自行编造。
- 非线性（`flowType: graph`）剧本的分支跳转词各不相同，不直接套用本段，按各出口的
  `condition` 分别写，并保持“单独成条、逐字匹配”的同一条原则。
