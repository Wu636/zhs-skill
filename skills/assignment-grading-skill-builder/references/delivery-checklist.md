# 学生要求、验证与交付清单

## 1. 批阅名称

- 能区分课程和作业类型；
- 通常 8-20 个中文字符；
- 不写“最新版”“测试版”等易过期词，除非教师明确需要。

## 2. 批阅描述

一段话回答：

- 批什么作业；
- 学生证据可能是什么格式；
- 按哪些模块/尺度评分；
- 是否用教师样本校准；
- 输出什么评价。

避免重复整份题目，不暴露样本姓名和具体分数文件名。

## 3. 学生提交作业要求模板

```text
请围绕【任务主题】完成【总任务】。

必交成果：
1. 【成果一】：【核心内容与质量要求】；
2. 【成果二】：【核心内容与质量要求】；
...

可选成果：
- 【可选内容】；未提交不影响对应必交成果认定。

提交方式：
- 【格式 A】或【格式 B】任选一种即可；
- 多个文件可合并为【容器格式】；
- 确保页面/音频/视频完整可打开，图表文字清晰，链接可访问；
- 引用与 AI 使用按题目要求注明。
```

检查所有“或/和”“必交/可选”是否准确。学生不需要同时提交的等价格式，明确写“任选一种”。

## 4. 课程 skill 静态验证

- [ ] 通过 `validate_grading_skill.py`；
- [ ] 通过 skill-creator `quick_validate.py`；
- [ ] frontmatter name 与根目录一致；
- [ ] 根目录只有 README.md、SKILL.md，以及按需存在的 references/、scripts/；
- [ ] README.md 使用批阅模板结构说明；
- [ ] 无 agents/、assets/ 或其他模板外目录；
- [ ] description 触发范围明确；
- [ ] score 类型唯一、满分存在、分值和正确；
- [ ] evaluations 至少含综合评语和可执行建议；
- [ ] 主文件引用的本地资源均存在；
- [ ] 无 TODO、模板占位符、无效图标路径；
- [ ] scripts 运行 `--help`，并对最小输入试跑；
- [ ] JSON 示例语法有效；
- [ ] 课程规则、样本锚点和学生要求对必交/可选的表述一致。

## 5. 回归测试记录

保存不含身份信息的内部表：

| 匿名样本 | 教师标签 | 覆盖模块 | 模型结果 | 分差/档位 | 主要偏差 | 修改 | 复测 |
|---|---|---|---|---|---|---|---|

每次修改后全量复测，记录是否出现回归。最终 skill 可保留匿名化锚点，不打包内部测试原件。

## 6. ZIP 交付检查

- [ ] ZIP 文件名清楚；
- [ ] 解压后只有一个课程 skill 根目录；
- [ ] 根目录内直接可见 `README.md` 和 `SKILL.md`；
- [ ] 不含另一个多余父目录；
- [ ] 不含 `agents/`、`assets/` 或产品配置文件；
- [ ] 不含 `.DS_Store`、`__MACOSX`、`__pycache__`、`.pyc`、临时图像、原始样本；
- [ ] 从 ZIP 解压后的目录再次运行验证器；
- [ ] 最终答复同时包含批阅名称、描述、学生提交要求和 ZIP 链接。
