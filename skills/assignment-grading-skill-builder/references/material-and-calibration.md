# 材料分析与教师样本校准

## 1. 材料角色

| 角色 | 典型文件 | 用途 | 是否可改写硬规则 |
|---|---|---|---|
| 当前权威要求 | 完善版/最终版题目、评分表 | 定义成果、分值、格式、必交性、扣分 | 是 |
| 教师最新说明 | 聊天截图、补充文字、口头确认记录 | 解决歧义、覆盖旧说明 | 是 |
| 教师数值样本 | 95/85/75 文件夹或成绩表对应附件 | 校准教师分数尺度 | 否，只校准 |
| 教师等级样本 | 优秀/中等/较差文件夹 | 校准覆盖模块的档位特征 | 否，只校准 |
| 普通学生样本 | 未给分附件 | 测试格式和常见问题 | 否 |
| 模板 | 作业批阅 skills 模板 ZIP | 定义平台结构与输出契约 | 定义结构，不定义课程内容 |

文件名带“完善/优化”只是候选信号，仍须结合用户说明、修改时间和内容确认。冲突时建立可追溯的决策表，不静默混用多个版本。

## 2. 样本覆盖矩阵

每个样本先填写：

| 样本 ID | 教师标签 | 实际成果 | 可评模块 | 缺失模块 | 质量证据 | 仅格式信息 |
|---|---|---|---|---|---|---|

“未出现”有两种含义：

- 该历史任务原本不要求：不将其视为样本缺陷，只标为未覆盖；
- 当前完整任务明确要求但学生漏交：正式评分对应模块为 0。

构建者要根据时间版本和教师说明区分二者。历史样本覆盖归一化只用于调试，不进入正式成绩。

## 3. 数值分数校准

### 建立锚点

对每个教师数值样本记录：

- 教师总分和已有分项分；
- 作业覆盖成果；
- 每个模块的正向证据和明确失分；
- 可能的封顶、缺项或格式等价关系；
- 教师评语中的尺度词。

先比较排序是否正确，再比较绝对分数。若 A 教师分高于 B，技能应在可观察质量相同覆盖下保持排序。样本很少时使用区间，不把一个样本的偶然细节写成普遍规则。

### 盲测

1. 复制或重命名样本到不含分数/等级的临时路径；
2. 给批阅模型的输入不含教师标签；
3. 记录模型总分、分项、主要证据和教师分；
4. 计算绝对误差并检查模块误差来源；
5. 调整评分锚点或证据解释，再全部回归，避免只修一个样本破坏其余样本。

默认质量线：平均绝对误差 <= 5，单例尽量 <= 8；课程或用户可给更严格阈值。若样本自身只有部分模块，不计算正式总分误差，只比较对应模块或使用教师给出的部分分。

## 4. 等级样本校准

等级样本不提供精确总分。按课程官方区间将“优秀/中等/较差”映射到对应模块的高/中/低档，而不是擅自定成 95/85/75。

提取可重复特征：

- 优秀样本共有、且能由作业内容直接观察的特征；
- 中等样本与优秀样本的关键差异；
- 较差样本仍然成立的基本证据和真正拉低质量的问题；
- 篇幅、模板、题材、文件名等无关特征。

校准参考应匿名描述，如“优秀锚点 A：中心问题清楚、证据链完整”，不复制学生原文，不保留姓名/学号。

## 5. 模块无样本时

- 保留权威题目给出的成果、分值和分档；
- 把该模块标记为“量表直接评分，暂无教师样本校准”；
- 使用合成边界案例测试：完整高质量、部分完成、只有形式、完全缺失；
- 后续取得教师样本后，只更新校准参考和回归测试，不随意改动已确认的硬规则。

## 6. 防止标签泄漏

课程 skill 必须写明：

- 新作业评分不读取目录中的优秀/中等/较差/分数；
- 姓名、学号、班级不进入分数依据；
- 脚本可提示路径含标签，但不得据此赋分；
- 打包前移除原始样本；
- 回归样本采用匿名 ID 和内容盲测。

## 7. 调优顺序

出现分差时按顺序排查：

1. 文件是否完整读取，等价格式是否被误判缺失；
2. 是否把一个问题重复扣在多项；
3. 是否忽略了谱面、图表、音频、视频中的直接证据；
4. 是否把页数、篇幅、术语数量或排版当质量；
5. 教师样本对应的是整份作业还是部分模块；
6. 分档描述是否过宽或过严；
7. 封顶/统一扣分是否有明确证据。

只有排查后仍有系统偏差，才修改锚点或权重，并记录修改对所有样本的影响。

## 8. 按格式取证（含旧版 .doc 报告）

学生报告常见形态是“学院模板 + 空白正文 + 贴图照片”，原始数据只在图片里。只读文字层会把整份作业判成未提交，取证必须先定格式。

| 格式 | 取文字 | 取嵌入图片 |
|---|---|---|
| .docx | `pandoc x.docx -t markdown`（公式会导出为 `$...$`）或解压 `word/document.xml` | `unzip -l x.docx | grep media/`，再解压 `word/media/` |
| .doc | `textutil -convert txt -output out.txt x.doc` | 可尝试 `qlmanage -o <outdir> -p x.doc`，若生成 `<outdir>/x.doc.qlpreview/Attachment*.jpeg|png`，须对照原文核对图片数量、分辨率与内容完整性，不能默认已取全原图 |
| .pdf | `pdftotext` / 逐页渲染 | 渲染成图再看 |

- `textutil -convert txt|docx|rtfd` 会丢掉嵌入图片（转换后 `media/` 为空），不能拿它取证图片内容。
- 不要在 OLE 二进制里按 JPEG/PNG 文件头截取：Word 图形流分片存储，截出来是半张彩色噪点图，会被误判成“学生图片损坏”。
- 手写记录表照片要逐张看：读数、盘位、点号、限差只能从照片取，文字层为空不等于缺交。
- 表格跨页拼接的照片（上下两张接缝错位）按“不可读待复核”处理，不据此判数据错。

## 9. 课程未给限差数值时

指导书常只写“不超过允许误差范围值”，或关键公式在原文里是图片（文本提取拿不到）。处理顺序：

1. 先回原文找：docx 的公式对象、PDF 表格图、记录表模板里的限差栏；
2. 仍找不到才自定，并单独列为“内部参考口径”，与课程原文限差分开写在不同小节；
3. 课程 skill 正文必须规定：按参考口径判为不合格时，扣分证据要注明“参考口径、非课程原文限差”，且扣分幅度受限（只处理明显超限，临界值进复核）；
4. 整门课都没有教师分数时，在 `references/calibration-record.md` 明写“未经教师分数校准”，列样本覆盖表与边界自测结论；不得用假设分数反推权重；
5. 大纲与指导书版本不一致（例如大纲加了新要求而指导书没有）时，按新版本纳入得分点，并在校准记录里注明“暂无样本覆盖”。
