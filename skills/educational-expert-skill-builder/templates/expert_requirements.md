# 教学专家需求采集表

教师可以只填已明确的部分。生成时从已有资料提取字段，优先追问会改变交付的缺项。

| 字段 | 可填写内容 |
| --- | --- |
| 专家名称 | 拟用名称或请生成 |
| 面向对象 | 专业、年级、学习基础、教师或学生 |
| 使用场景与教学目标 | 在什么任务中使用，希望学生学会什么 |
| 核心任务及优先级 | 希望专家处理哪些具体问题，优先满足哪几项 |
| 互动方式 | 直接答疑、分步引导、出题批改、讨论或其他 |
| 用户提交材料 | 文件类型、数据字段、图像、报告、教师指导书 |
| 教材与资料入口 | 书名、版本、链接、可提供的原文或平台导出 |
| 评价标准 | 教师量表、权重、示例、缺交规则 |
| 交付与模板 | 专家描述、指令、反馈表、报告、ZIP 或其他 |
| 边界与权限 | 实操、医疗、平台访问或发布方面的条件 |
| 验收重点 | 最希望确认的典型情境或容易出现的错误 |
