# 批阅技能 · 文件结构说明

每个批阅技能 = 一种作业类型的完整批阅能力，按以下结构组织。

```
<skill-name>/                 技能根目录，名称用小写连字符（= SKILL.md 的 name）
├── SKILL.md                  【必需】技能定义：批阅流程 / 评分方式 / 评价项 / 客观展示项
├── references/               【可选】批阅时按需读取的参考资料
│   └── eval-detail.md        【可选】过长的评价项生成细则（SKILL.md 放不下时外移，正文给出指引）
├── scripts/                  【可选】确定性处理脚本，供批阅时调用
│   └── ...
```

## 必需 / 可选

- `SKILL.md`：唯一必需文件。三个必填模块：frontmatter（技能名称和描述）、评分项 score、评价项 evaluations（默认有综合评语和改进建议、可为空）。
- `references/`、`scripts/`：均按需添加，无则可省略。

## 评分项
1. 评分项必须存在；`score_type` 只能三选一且合法（dimension / gradient / item 之一）。
2. 按所选 `score_type`，必须能识别出以下字段且均不为空：
| score_type | 必须能识别且非空的字段 |
| 维度评分 dimension | 满分值；各维度的 名称 & 分值 & 描述 |
| 梯度评分 gradient | 满分值；各梯度的 分值（或分值范围）& 标签（如 A/B/C/D 或 优/良/中/差）& 描述 |
| 逐项评分 item | 满分值；拆项方式描述；各评分项的 编号 & 分值 & 评分项内容 & 评分规则 |

## 渲染方式

- **评分项（score）**：固定结构输出。技能输出总分值、各项打分和打分原因，平台**直接渲染**。
- **评价项（evaluations）**：技能自由输出 JSON（字段结构自定，无需声明 UI 样式），由平台 **A to UI** 层根据输出的 JSON 自动判断样式并渲染。

## 平台约定（技能无需定义）

- 总分块：由技能输出最终总分值（含多子单元归并后的总分）；平台仅负责将总分块展示在报告顶部，不重新计算。
- 评价项的界面：由平台 AUI 层根据技能输出的 JSON 自动判断样式并生成。
- 默认展示顺序：按 SKILL.md 中各模块从上至下的书写顺序展示。
