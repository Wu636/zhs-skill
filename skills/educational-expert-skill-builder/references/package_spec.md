# 标准专家 Skill 包

## 约定文件

| 路径 | 内容 |
| --- | --- |
| `SKILL.md` | 入口。YAML 顶部信息含 `name` 和 `description`。正文写运行步骤和必要的相对链接。 |
| `EXPERT_CUSTOM.md` | 显示名称、简介、三段式具体描述、可独立粘贴的专家指令。可加一句建议开场。 |
| `README.md` | 使用方式、文件结构和必须由教师补充的材料。 |
| `manifest.json` | 包内文件清单。沿用 `name`、`display_name`、`version`、`language`、`entrypoint`、`expert_custom`、`resources`；按需补充对象、能力和边界。 |
| `references/` | 学科资料、数据格式、评分依据、专业边界或工作流，按实际需要拆分。 |
| `templates/` | 专家运行时实际复用的输出模板或表单。 |
| `examples/test_cases.md` | 面向本包对应专家的可复制提问、测试材料与预期行为。 |

根目录用小写英文字母、数字和连字符命名，并与 `SKILL.md` 和 `manifest.json` 的 `name` 一致。ZIP 内只放一个根目录，不夹带外层工作目录、系统隐藏文件、临时产物、未经授权纳入的学生原件或凭证。默认使用“专家名称_skill_标准文件夹结构版.zip”作为交付名。既有专家的命名和目录约定优先。

## 交付检查

- 对外名称、受众和功能在入口、介绍及清单中一致。三段式具体描述可直接粘贴。
- 入口能找到需要使用的参考与模板。清单路径存在，模板和案例与实际学科及任务相符。
- 更新既有包时，检查修改是否贯穿所有受影响的文件。保留兼容入口，按已有版本约定更新版本。
- 归档可打开，文件内容可读取，根目录唯一。向用户提供实际生成的下载链接。生成包的结构检查与专家的对话验收分别记录。

## 使用归档工具

从生成器目录运行以下命令，将两个路径换成实际文件位置。

```text
python3 scripts/pack_skill.py path/to/target-skill path/to/delivery.zip
```

工具使用 Python 3 标准库，检查目录名、入口名称、必需文件、资源清单和 ZIP 完整性。它收录四个必需根文件和清单 `resources` 中列出的文件。额外脚本或素材也要列进清单。归档目标放在源目录外。若已有同名 ZIP，选择新路径，或在确认覆盖该交付文件时使用 `--replace`。目标环境有通用 Skill 校验器时，可进一步检查完整 YAML。
